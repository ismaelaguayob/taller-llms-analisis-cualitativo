Taller de Análisis Cualitativo con LLMs desarrollado junto a [Exequiel Trujillo](https://github.com/exetrujillo) para LatinR 2025.

- Revisamos los últimos avances en análisis cualitativo con Inteligencia Artificial, para enseñar un flujo de trabajo informado con LLMs
- Abordamos diferentes técnicas de prompt y validación para mantener un proceso riguroso, desde un rol de colaboración constante entre investigador e IA (donde el LLM es una herramienta)
- Automatizamos todo el proceso, para iterar sobre grandes volúmenes de datos
- Tratamos diferentes técnicas de exploración, reporte e interpretación de los resultados, para llegar a conclusiones sustantivas
- Discutimos sobre las implicaciones de estos avances, resaltando oportunidades, limitaciones, desafíos y propuestas
